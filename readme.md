#StrainCorr-2D-DIC-V2.0-Beta
Digital Image Correlation 数字图像相关软件

StrainCorr is a desktop 2D digital image correlation application for project
management, AOI definition, displacement/strain computation, visualization,
reporting, and the local StrainClaw assistant. The production solver is the
self-developed StrainCorr native C++ kernel exposed to the PySide6 application
through a Python adapter.
